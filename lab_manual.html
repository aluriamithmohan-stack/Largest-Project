SET-NO: 06
Question 6: Largest of Three Numbers
6.a. Write a program to find the largest among three numbers. Upload the program to GitHub using Git.
6.b. Configure a Jenkins build job and deploy a sample containerized application using Kubernetes.
Aim
To write a Java program to find the largest among three numbers, create a GitHub repository and upload the program using Git, configure a Jenkins Freestyle build job to compile, execute the program, build a Docker image, and deploy a sample containerized application using Kubernetes.
6(a). Write a Program to Find Largest of Three Numbers and Upload to GitHub Using Git
Step 1 Install the required software

Install Java JDK, Git, and Visual Studio Code. Create or sign in to a GitHub account. Open Command Prompt and verify:

javac -version java -version git --version
Step 2 Create a project folder

Open File Explorer and create a folder named Largest-Project (or open c:\Users\amith\Desktop\Devops).

Open Visual Studio Code → Select File → Open Folder and choose your project folder.

Step 3 Write the Java largest of three numbers program

Create a file named Largest.java and enter the following code:

import java.util.Scanner; public class Largest { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Enter first number: "); int num1 = sc.nextInt(); System.out.print("Enter second number: "); int num2 = sc.nextInt(); System.out.print("Enter third number: "); int num3 = sc.nextInt(); int largest; if (num1 >= num2 && num1 >= num3) { largest = num1; } else if (num2 >= num1 && num2 >= num3) { largest = num2; } else { largest = num3; } System.out.println("The largest number is: " + largest); sc.close(); } }
Step 4 Compile and execute the Java program

Open Terminal (Terminal → New Terminal) in VS Code and execute:

javac Largest.java java Largest

Enter three numbers when prompted (e.g. 15, 42, 28). Expected output: The largest number is: 42.

Step 5 Create a GitHub repository
  1. Open https://github.com and sign in.
  2. Click the + icon at the top-right corner → select New repository.
  3. Enter repository name as Largest-Project (or Devops).
  4. Select Public (or Private) → click Create repository.
Step 6 Upload the Java program using Git

In the VS Code terminal in the project folder, execute the following commands one by one:

git init git add Largest.java git commit -m "Initial commit: Largest of three numbers program" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/Largest-Project.git git push -u origin main
Step 7 Verify the GitHub repository

Open your GitHub account in a browser, navigate to Largest-Project, and verify that Largest.java is displayed in the repository.

6(b). Configure Jenkins, Build Docker Image & Kubernetes Deployment (Part 1 - Configuration)
Step 8 Create a Dockerfile

In the project folder, create a file named Dockerfile (without any file extension) and enter:

FROM eclipse-temurin:21-jdk WORKDIR /app COPY Largest.java . RUN javac Largest.java CMD ["java", "Largest"]
Step 9 Create Kubernetes deployment file & upload to GitHub

Create a file named deployment.yaml to deploy a sample Nginx container using Kubernetes:

apiVersion: apps/v1 kind: Deployment metadata: name: nginx-deployment spec: replicas: 1 selector: matchLabels: app: nginx template: metadata: labels: app: nginx spec: containers: - name: nginx image: nginx:latest ports: - containerPort: 80 --- apiVersion: v1 kind: Service metadata: name: nginx-service spec: type: NodePort selector: app: nginx ports: - port: 80 targetPort: 80 nodePort: 30080

Upload the Dockerfile and deployment file to GitHub before configuring Jenkins:

git add Dockerfile deployment.yaml git commit -m "Add Dockerfile and Kubernetes deployment" git push origin main
Step 10 Install and start Docker Desktop
  1. Download and install Docker Desktop for Windows from docker.com.
  2. Open Docker Desktop and wait until the Docker Engine status shows Running.
  3. (Enable Kubernetes): In Docker Desktop → Settings → Kubernetes → Check "Enable Kubernetes" → Apply & restart.
  4. Open Command Prompt and verify:
    docker --version docker info
Step 11 Build and test the Docker image manually

In the project folder terminal, execute:

docker build -t largest-app . docker images docker run -it largest-app
Step 12 Install and configure Jenkins
  1. Install Jenkins and open a web browser at http://localhost:8080.
  2. Obtain initial password from: C:\ProgramData\Jenkins\.jenkins\secrets\initialAdminPassword.
  3. Paste password, select Install suggested plugins, and create an administrator account.
Step 13 Create a Jenkins job
  1. Open http://localhost:8080 and sign in → click New Item → enter job name as Largest-Docker-Job.
  2. Select Freestyle project → click OK.
6(b). Configure Jenkins, Build Docker Image & Kubernetes Deployment (Part 2 - Pipeline & Deploy)
Step 14 Connect Jenkins with GitHub

In job configuration → Source Code Management:

  1. Select Git → Repository URL: https://github.com/YOUR_USERNAME/Largest-Project.git
  2. Set Branch Specifier to */main | Credentials: - none - (for public repositories).
Step 15 Configure the Jenkins build commands

Under Build Steps → click Add build step → Execute Windows batch command. Enter:

echo ===== Compiling Java Program ===== javac Largest.java echo ===== Executing Java Program ===== echo 15 42 28 | java Largest echo ===== Building Docker Image ===== docker build -t largest-app . echo ===== Listing Docker Images ===== docker images

Click Apply → Save.

Step 16 Execute the Jenkins job
  1. Open Jenkins dashboard → select Largest-Docker-Job → click Build Now.
  2. Click on the build number (e.g. #1) → select Console Output.
  3. Verify that the Java program compiles, outputs The largest number is: 42, and Docker image builds with Finished: SUCCESS.
Step 17 Deploy sample containerized application using Kubernetes

Open Command Prompt or VS Code terminal in the project folder and deploy the Kubernetes manifest:

kubectl apply -f deployment.yaml
Step 18 Verify Kubernetes pods, services and container execution

Check the status of running pods and exposed services using:

kubectl get pods kubectl get services

Open your browser at http://localhost:30080 to view the running Nginx welcome web page.

★ Practical Exam Viva-Voce / Key Explanations Reference
Q1. What is the role of Git vs GitHub? Ans: Git is a local version control system tracking code revisions. GitHub is a remote cloud repository for collaboration and triggering CI/CD.
Q2. What is the difference between Docker image and container? Ans: An image is a read-only template built from a Dockerfile; a container is a live running instance of that image.
Q3. Why do we use Jenkins in this pipeline? Ans: Jenkins automates continuous integration: pulling source from GitHub, compiling Java, and building the container artifact automatically.
Q4. What is a Kubernetes Pod and Service? Ans: A Pod is the smallest deployable execution unit containing containers. A Service (NodePort) exposes the Pod to external user traffic.
